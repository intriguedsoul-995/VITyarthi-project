# VITyarthi-project
PROJECT TITLE - LIVE WEATHER DESKTOP NOTIFICATION
<br>
<br>
OVERVIEW OF PROJECT - IT IS AN LIGHTWEIGHT APPLICATION THAT FETCHES REAL-TIME METROLOGICAL DATA VIA AN API AND PUSHES IT DIRECTLY TO YOUR OPERATING SYSTEM 'S NOTIFICATION CENTER
<br>
<br>
FEATURES 
<br>
1) AUTOMATICALLY FINDS THE LATITUDE AND LONGITUDE OF THE GIVEN CITY
<br>
2) FETCHES REAL-TIME WEATHER INFORMATION WITHOUT REQUIRING AN API KEY
<br>
